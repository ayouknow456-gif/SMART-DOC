# SMART DOC

ระบบเทมเพลตเอกสารราชการ — สร้าง บันทึกข้อความ หนังสือลาออก หนังสือขอความอนุเคราะห์ และหนังสือรับรอง พร้อมเครื่องมือจัดรูปแบบตัวอักษร ตาราง รูปภาพ และเส้นกำกับโครงเอกสาร (ระยะขอบ / ขนาดตราครุฑ)

เป็นเว็บแอปแบบ **static** (HTML + CSS + JavaScript ล้วน ไม่มีขั้นตอน build) จึงเปิดใช้งานบน GitHub Pages ได้ทันที

## ฟีเจอร์

- **เทมเพลตเอกสาร** 4 แบบ: บันทึกข้อความ, หนังสือลาออก, หนังสือขอความอนุเคราะห์, หนังสือรับรอง (เพิ่มแบบใหม่ได้ที่ `js/templates.js`)
- **จัดรูปแบบตัวอักษร**: ฟอนต์, ขนาด, ตัวหนา/เอียง/ขีดเส้นใต้, การจัดหน้า (ซ้าย/กึ่งกลาง/ขวา/กระจาย), ระยะบรรทัด, ย่อหน้า
- **ตาราง**: แทรกตารางด้วยการเลือกจำนวนแถว/คอลัมน์ พิมพ์ข้อมูลในตารางได้โดยตรง
- **รูปภาพ**: อัปโหลดรูปจากเครื่อง แทรกเข้าเอกสารได้ทันที
- **โครงเอกสาร (toggle ได้)**:
  - เส้นขอบระยะขอบกระดาษ (เส้นประสีน้ำเงิน — ห้ามพิมพ์เกินเส้นนี้) ปรับระยะบน/ล่าง/ซ้าย/ขวาได้เป็นเซนติเมตร
  - กรอบตราครุฑ ปรับขนาดเป็นเซนติเมตร
  - เส้นบรรทัดอ้างอิงสำหรับจัดวางข้อความให้ตรงแนว
- **บันทึกฉบับร่าง**: เก็บไว้ใน localStorage ของเบราว์เซอร์ (ไม่ส่งข้อมูลออกไปที่เซิร์ฟเวอร์ใด ๆ)
- **พิมพ์ / บันทึกเป็น PDF**: ใช้ฟังก์ชันพิมพ์ของเบราว์เซอร์ (Ctrl/Cmd+P) จัดหน้ากระดาษ A4 อัตโนมัติ

## โครงสร้างโปรเจกต์

```
smart-doc/
├── index.html          หน้าเว็บหลัก
├── css/style.css        สไตล์ทั้งหมด
├── js/templates.js      ข้อมูลเทมเพลตเอกสาร (แก้ไข/เพิ่มแบบฟอร์มที่นี่)
├── js/app.js             ตรรกะของแอป (toolbar, guides, save/load, print)
└── README.md
```

## วิธีนำขึ้น GitHub และเปิดใช้งานผ่าน GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `smart-doc`
2. ในเครื่อง เปิด terminal ที่โฟลเดอร์นี้แล้วรัน:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: SMART DOC"
   git branch -M main
   git remote add origin https://github.com/<username>/smart-doc.git
   git push -u origin main
   ```
3. ไปที่ repository บน GitHub → **Settings → Pages**
4. หัวข้อ **Build and deployment** เลือก Source: **Deploy from a branch**
5. เลือก Branch: `main`, Folder: `/ (root)` แล้วกด **Save**
6. รอสักครู่ เว็บจะเผยแพร่ที่ `https://<username>.github.io/smart-doc/`

## การเพิ่มแบบฟอร์มเอกสารใหม่

เปิดไฟล์ `js/templates.js` แล้วเพิ่มอ็อบเจกต์ใหม่ในอาร์เรย์ `TEMPLATES` ตามรูปแบบเดิม (มี `id`, `name`, `code`, `html`) ระบบจะแสดงในรายการแบบฟอร์มด้านซ้ายให้อัตโนมัติ

## หมายเหตุ

- ตราครุฑแสดงเป็นกรอบระบุขนาดเท่านั้น (ไม่มีไฟล์ภาพตราครุฑแนบมาด้วยเหตุผลด้านลิขสิทธิ์/ความเหมาะสม) — ผู้ใช้สามารถอัปโหลดไฟล์ภาพตราครุฑของหน่วยงานตนเองผ่านปุ่ม "แทรกรูปภาพ" แล้ววางในตำแหน่งกรอบที่กำหนดได้
- ขนาดกระดาษเป็น A4 (21 × 29.7 ซม.) ตามมาตรฐานเอกสารราชการไทย
- ฉบับร่างที่บันทึกไว้จะอยู่ในเบราว์เซอร์เครื่องนั้น ๆ เท่านั้น หากล้างข้อมูลเบราว์เซอร์จะหายไปด้วย
